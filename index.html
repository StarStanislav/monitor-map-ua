Джерело даних
Дані про активні повітряні тривоги отримуються через відкритий API NEPTUN.

Дані: Карта повітряних тривог — NEPTUN
Важливо
NEPTUN є інформаційним агрегатором і не замінює офіційні сигнали повітряної тривоги. У разі оголошення офіційної тривоги користуйтеся офіційними сповіщеннями та прямуйте до укриття.
